# Ticket Automation V1

A safe browser-based prototype for an L3 ticket automation dashboard.

## V1 features
- Ticket summary cards
- Pending ticket filtering
- Stop & Return filtering
- No Ops Response filtering
- Review action
- Simulation-only action
- Responsive layout for tablet/mobile

## Important
This version does **not** connect to any company ticketing system and does not modify real tickets.

## Run
Open `index.html` in a browser, or serve the folder with any simple static web server.
